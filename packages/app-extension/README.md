# Quasar App Extension QIconPicker

The **QIconPicker App Extension** adds the [QIconPicker](../ui) component to a Quasar CLI Vite application. It registers the boot file and adds the QIconPicker stylesheet for you.

## QIconPicker v3.0.0 Beta

QIconPicker v3 prepares the app extension for Quasar CLI Vite 3. The app extension requires `@quasar/app-vite` >=3.0.0-beta.44 and no longer supports webpack-based Quasar apps. If your application is still using `@quasar/app-webpack`, migrate the application to Quasar CLI Vite before installing QIconPicker v3.

## Install

```bash
quasar ext add @quasar/qiconpicker
```

While QIconPicker v3 is in beta, install with:

```bash
quasar ext add @quasar/qiconpicker@beta
```

## Uninstall

```bash
quasar ext remove @quasar/qiconpicker
```

## Describe

When installed as an App Extension, you can use:

```bash
quasar describe QIconPicker
```
