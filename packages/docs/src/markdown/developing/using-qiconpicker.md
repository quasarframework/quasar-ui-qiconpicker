## QIconPicker Examples

Most examples use built-in `icon-set` values so they match normal application usage. Examples that use `icon-set` stay source-only because the UMD bundle cannot lazy load `@quasar/extras` ESM icon-set modules without a bundler.

For custom icon arrays, slot rendering, pagination control, and bundle tradeoffs, see the [Advanced guide](/developing/advanced).
